# CLAUDE.md

Guidance for working in the Openweek repo. Keep this file and `/docs` in sync as the stack evolves.

## What this is
Openweek — a free, AGPL-3.0, **self-hostable weekly planner**. A paper-planner week grid (7 day columns +
"Someday"-style lists) of draggable, checkable, color-tagged tasks, with **read-only** calendar sync
(Google / CalDAV / iCal). Single Nuxt 4 app + Postgres; `docker compose up` to self-host.

## Commands
```bash
pnpm dev            # dev server at http://localhost:3000
pnpm build          # production build (.output)
pnpm typecheck      # vue-tsc — BLOCKING gate (the default build does not type-check)
pnpm lint           # @nuxt/eslint (flat config)
pnpm test           # Vitest
pnpm test:coverage  # coverage report
pnpm db:generate    # generate a migration after editing the schema   (Phase 1+)
pnpm db:migrate     # apply migrations                                (Phase 1+)
pnpm auth:gen       # regenerate Better Auth tables after auth changes (Phase 1+)
```
Before any PR: `pnpm lint && pnpm typecheck && pnpm test` must be green.

## Structure (Nuxt 4 three-root)
- `app/` — Vue front-end (`pages/`, `components/`, `stores/` Pinia, `composables/`, `middleware/`, `assets/css/`)
- `server/` — Nitro (`api/`, `database/{client,schema,migrations}`, `utils/{auth,config,crypto}`, `services/`, `tasks/`)
- `shared/` — Zod `schemas/` (the API contract, imported by client **and** server), `constants/`, `types/`
- `docs/` — the design/architecture docs above

## Conventions
- **Typed API without tRPC** — request/response shapes are Zod schemas in `shared/schemas/`; endpoints
  `parse()` input, clients import the types. Every app row is scoped by `userId`.
- **IDs & ordering** — app tables use **uuidv7** PKs; ordering is a fractional `position` string
  (`fractional-indexing-jittered`); always sort `(position, id)`.
- **A task is on a day XOR in a list** — `CHECK (num_nonnulls(date, list_id) = 1)`.
- **Drizzle owns migrations.** Better Auth tables are generated by `@better-auth/cli` and committed; never let
  the auth CLI migrate. Keep `@better-auth/cli` pinned to `better-auth`.
- **Optimistic UI** — the week grid is one Pinia store; mutate locally, fire the request, roll back on error.
- **DnD always has a keyboard path** — pair every drag with the "Move to…" menu.
- **Design tokens are CSS variables** (`--ow-*`); don't hard-code the hex values from `docs/design.md` in
  components — reference the tokens.
- **Config fails fast** — `server/utils/config.ts` validates env with Zod at boot.
- **Fonts are self-hosted** (`@fontsource/ibm-plex-mono` + `-sans`); no CDN.

## Build order
Follow the phases in [`docs/roadmap.md`](docs/roadmap.md). Status: **v1 scaffolded (Phases 0–9 implemented)** —
tasks/lists/grid, drag-and-drop, rollover, read-only calendar sync (Google/CalDAV/iCal), search, and the

reminders, two-way sync, offline/PWA, month view.
